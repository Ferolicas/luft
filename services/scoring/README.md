# LUFT Scoring

Servicio interno y no expuesto por Nginx. La versión inicial usa reglas explicables y versionadas; `model_used=false` evita presentar un modelo estadístico como entrenado antes de contar con una muestra aprobada y auditada.

La activación futura de un modelo exige validación de sesgo por estrato, sexo, ubicación y edad, aprobación del área de riesgo, versionado del artefacto y posibilidad de explicación humana.
